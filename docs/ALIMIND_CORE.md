# AliMind — Ядро системы

## Ядро

Ядро AliMind — официальная и открытая информация.

Она переносится из сайтов в Telegram-бот для удобства.

Примеры:

События города

* дежурные аптеки
* отключения воды
* отключения электричества

ВНЖ

* правила
* документы
* изменения

AliMind не создаёт информацию.
Он только делает её удобной.

---

## Слои вокруг ядра

Вокруг ядра создаются слои удобства.

Примеры:

Цены города

* аренда жилья
* недвижимость
* прокат авто

Навигация по сервисам

Диалог бота

---

## География

Проект имеет архитектуру для разных городов.

Но текущий пилот:

Город — Алания.

---

## Роль агента

Обновление данных выполняет агент.

Причина:

человек может забыть
человек может заболеть
человек может отдыхать

Агент работает по расписанию.

---

## Поведение при отсутствии данных

Если данные отсутствуют:

система честно сообщает

"Нет данных".
