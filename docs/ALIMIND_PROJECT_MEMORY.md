## DELIVERY TRANSPORT DECISION — ЗАКРЕПЛЕНО

Заявки партнёрам доставляются ТОЛЬКО в личные сообщения партнёра (private chat).

❌ не в канал  
❌ не в публичные чаты  

Причины:
1. Ограничения Telegram на отправку сообщений ботом в каналы
2. Канал ≠ CRM
3. Private chat:
   - гарантированная доставка
   - нет утечек данных
   - не требует админских прав
   - масштабируется на N партнёров

Инвариант:
- канал и бот живут независимо
- единственная точка входа — кнопка «📨 Оставить запрос»
- все заявки → `partner_links.json` → private chat партнёра

## ADMIN CONTROL + FUNNEL METRICS (V3) — ЗАКРЕПЛЕНО

Статус:
🟢 STABLE · CONTROLLED · READY FOR SCALE

Цель:
- скрытый админ-контур (виден только администратору)
- диагностика системы
- метрики воронки в процентах (Delivery / Fail / Not-connected / Partner response)

---

### Реализовано

#### 1) Admin Connect — DONE
Команда:
- `/admin_connect`

Поведение:
- назначает текущий чат админ-чатом
- уведомляет: «Уведомления будут приходить в этот чат»

Примечание:
- если `admin_chat_id` хранится in-memory — при рестарте требуется повторный `/admin_connect`

---

#### 2) Admin Status — DONE
Команда:
- `/admin_status`

Возвращает:
- `admin_chat_id`
- `partner_links: OK`
- `audit_log: OK`
- `time: <UTC>`

Назначение:
- проверка целостности состояния перед масштабированием

---

#### 3) Admin Funnel — DONE
Команда:
- `/admin_funnel`

Источник данных:
- `data/state/request_audit.jsonl` (append-only)

Показывает:
- счётчики событий: `preq_click`, `confirm_ok`, `confirm_fail`, `not_connected`
- проценты:
  - Delivery rate (ok / attempts)
  - Fail rate (fail / attempts)
  - Not-connected rate (nc / attempts)
  - Partner response rate (replied / ok)
  - Partner in-work rate (work / ok)
  - Partner decline rate (declined / ok)

Факты:
- команда корректно работает в админ-чате
- вне админ-чата админ-команды не светятся

---

#### 4) Admin Help — DONE
Команда:
- `/admin_help`

Содержимое:
- список админ-команд (status/funnel/connect/help)
- примечание: админ-команды работают только в админ-чате, вне его скрыты

---

### Security / UX Policy — ЗАКРЕПЛЕНО

1) Админ-команды доступны только в админ-чате:
- используется `admin_only` (по `admin_chat_id`)
- используется helper `is_admin_chat(chat_id)`

2) Маскировка админ-команд:
- любые `/admin_*` вне админ-чата → полная тишина (fallback не отвечает)
- админ-контур не раскрывается пользователям и партнёрам

3) Wiring-инвариант подтверждён:
- каждый router подключается ровно 1 раз
- fallback строго последним
- ошибка “Router is already attached…” устранена (дубль include_router)
