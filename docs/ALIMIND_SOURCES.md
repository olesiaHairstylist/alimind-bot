# AliMind — Источники данных

## Источники

AliMind использует только открытые источники.

Типы:

официальные сайты
открытые сайты
сайты объявлений

---

## Source Registry

В системе существует каталог источников.

Каждый источник описывается:

name
url
тип данных
частота обновления
статус

Пример:

name: alanya_pharmacies
type: CITY_EVENTS
url: https://site.com/pharmacies

---

## Модульность

Один источник = один парсер.

Примеры модулей:

pharmacies_source.py
water_source.py
electric_source.py

Это позволяет:

изолировать ошибки
быстро исправлять источник.

---

## Проверка данных

После парсинга выполняется проверка:

есть ли записи
не пустые ли поля
не исчезли ли данные.

Если вчера было 20 записей,
а сегодня 0 —

данные считаются ошибкой источника.

---

## Принцип

Лучше меньше источников,
но поддерживать их рабочими.
