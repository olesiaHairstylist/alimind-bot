# AliMind — Идея проекта

AliMind — это городской электронный помощник.

Система переносит официальную и открытую информацию из сайтов
в Telegram-бот для удобного доступа.

AliMind не заменяет источники информации.

Он делает информацию:

* доступной
* структурированной
* быстрой для получения.

---

## Основная цель

Быть полезным каждый день.

Человек открывает бота чтобы:

* найти дежурную аптеку
* узнать об отключении воды
* проверить цену аренды
* узнать правила ВНЖ
* найти сервис.

AliMind — это спокойный инструмент повседневной жизни города.

---

## Принципы системы

1. только факты
2. только открытые источники
3. короткие ответы
4. честность при отсутствии данных

---

## Что не делает AliMind

Система не является:

* маркетплейсом
* новостным каналом
* рейтинговой системой бизнеса
* социальной сетью

AliMind предоставляет только информацию.
