# AliMind — Product Map v1

## Общее описание

AliMind — это городской справочный Telegram-бот.

Он переносит официальную и открытую информацию из сайтов
в удобный интерфейс Telegram.

Система построена вокруг **справочного ядра**,
вокруг которого находятся дополнительные слои.

---

# 1. ЯДРО СИСТЕМЫ

Ядро AliMind — это открытая и официальная информация города.

Типы данных:

• дежурные аптеки  
• отключения воды  
• отключения электричества  
• контакты служб  
• требования ВНЖ  
• базовая городская инфраструктура

Принцип:

AliMind **не создаёт информацию**.  
Он **структурирует и ускоряет доступ к ней**.

---

# 2. СПРАВОЧНЫЙ СЛОЙ

Это основные разделы бота.

Главное меню:

1. События города  
2. Важные службы города  
3. ВНЖ  
4. Активная жизнь  
5. Недвижимость  
6. Транспорт  
7. Туризм  
8. Beauty

Этот слой формирует **ежедневную полезность бота**.

---

# 3. СЛОЙ СОБЫТИЙ

Отдельный тип данных — **временные события города**.

Примеры:

• дежурные аптеки  
• отключения воды  
• отключения электричества

Особенности:

• обновляются автоматически  
• не имеют истории  
• показывают только актуальный день.

---

# 4. СЛОЙ УСЛУГ

Поверх справочного слоя располагаются карточки специалистов.

Примеры:

• переводчики  
• агентства недвижимости  
• трансферы  
• тренеры  
• beauty мастера

Карточки:

• находятся внутри разделов  
• не находятся в главном меню  
• не перегружают интерфейс.

---

# 5. СЛОЙ МОНЕТИЗАЦИИ

Монетизация происходит через **партнёрские карточки**.

Модель:

Lead Tokens.

Партнёр платит:

не за размещение  
а за возможность получать заявки.

Списание происходит только при доставленном запросе.

---

# 6. DATA PIPELINE

Путь данных в системе:

Website  
↓  
Parser  
↓  
Validation  
↓  
Normalization  
↓  
Snapshot  
↓  
Telegram Bot  
↓  
User

Бот никогда не обращается к сайтам напрямую.

---

# 7. CITY EVENTS ENGINE

Отдельный модуль системы.

Функции:

• сбор данных  
• проверка данных  
• snapshot  
• публикация в боте.

Типы данных:

• pharmacies  
• water outages  
• electricity outages.

---

# 8. ИНФРАСТРУКТУРА

Система работает на следующем стеке:

Telegram Bot (aiogram)  
VPS сервер  
Scheduler  
Parsers  
JSON snapshots

---

# 9. ГЕОГРАФИЯ

Пилотный город:

Алания.

Архитектура позволяет масштабировать систему на другие города.

---

# 10. ПРИНЦИП ПРОЕКТА

AliMind — это:

тихий городской помощник.

Он не:

• новостной портал  
• маркетплейс  
• социальная сеть

Он:

• ориентирует  
• ускоряет поиск информации  
• помогает в повседневной жизни города.
