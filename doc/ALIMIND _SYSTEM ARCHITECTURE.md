# ALIMIND — SYSTEM ARCHITECTURE (MENU STRUCTURE)

Версия: v1.0
Статус: BASELINE LOCKED

---

# 1. Назначение документа

Документ фиксирует окончательную структуру верхнего меню Telegram-бота **AliMind**.

Цель документа:

* убрать архитектурную путаницу
* разделить справочную систему и каталог объектов
* сохранить устойчивость проекта при дальнейшем росте

Этот документ считается **опорной точкой интерфейса**.

Любые изменения должны быть осознанными.

---

# 2. Общая архитектура меню

Главное меню AliMind состоит из **трёх уровней смысловой логики**.

1️⃣ Справочное ядро города
2️⃣ Городские каталоги услуг
3️⃣ Сервисные разделы системы

---

# 3. Справочное ядро (основная ценность)

Этот слой является **основной причиной захода пользователя в бот**.

Разделы:

🌆 События города
☎️ Важные службы города
📄 ВНЖ
🚌 Транспорт

---

## 3.1 События города

Содержит оперативную инфраструктурную информацию.

Тип данных: **события**

Примеры:

* дежурные аптеки
* отключения воды
* отключения электричества

Данные обновляются автоматически агентом.

---

## 3.2 Важные службы города

Содержит контакты критически важных служб.

Тип данных: **объекты инфраструктуры**

Примеры:

* полиция
* скорая помощь
* пожарная служба
* экстренные телефоны

---

## 3.3 ВНЖ

Раздел информационного характера.

Содержит:

* требования документов
* правила
* изменения законодательства

Источники:

Только официальные документы.

AliMind **не оказывает юридических консультаций**.

---

## 3.4 Транспорт

Раздел городской навигации.

Примеры информации:

* автобусы
* транспортные маршруты
* трансфер
* городская логистика

---

# 4. Каталоги городских услуг

Этот слой содержит **карточки объектов**.

Он работает через существующий механизм:

`catopen:<category>`

Разделы:

🗣 Услуги переводчика
💇 Салон красоты
🍽 Кафе и рестораны
🚕 Такси
⚽ Спорт
🎭 Досуг

---

## 4.1 Поведение каталога

Каталог:

* показывает список объектов
* открывает карточку
* не является рекламной витриной

Партнёры могут иметь приоритет в списке.

---

# 5. Сервисный слой системы

Этот слой не относится к городской информации.

Он относится к работе самой платформы.

Разделы:

🤝 Стать партнёром AliMind
🤖 Бот для бизнеса

---

## 5.1 Стать партнёром

Форма подключения бизнеса к системе.

Партнёр получает:

* карточку
* приём заявок
* лид-модель через токены

---

## 5.2 Бот для бизнеса

Раздел демонстрирует возможности AliMind для бизнеса.

# 7. Архитектурный принцип

AliMind строится по модели:

**Справка → Польза → Сервисы**

Сначала человек получает информацию,
затем полезные городские сервисы,
и только потом видит бизнес-возможности.

---

# 8. Инварианты системы

Запрещено:

* смешивать справку и каталог
* перегружать меню
* добавлять случайные разделы

Любая новая функция должна **встраиваться в существующие разделы**, а не создавать новый.
