Status: ACTIVE SYSTEM
Version: v1

1. Назначение системы

AliMind — это городской Telegram-помощник для Алании.

Система объединяет:

городскую справочную информацию

каталог услуг и бизнеса

партнёрские карточки

сервисные модули

Главная идея:

быстрый доступ к нужной информации без поиска по десяткам сайтов.

2. Архитектурная модель

Система построена по принципу трёх слоёв.

INTERFACE
DATA
SERVICES
3. Слой интерфейса

Отвечает за взаимодействие с пользователем.

Расположен в:

bot/handlers
3.1 Главное меню

Файл:

handlers/start.py

Функции:

отображение главного экрана

стартовое изображение

навигация по разделам

универсальная кнопка возврата

3.2 События города

Файл:

handlers/city_today.py

Функции:

дежурные аптеки

отключения воды и электричества

навигация внутри раздела

3.3 Экстренные службы

Файл:

handlers/emergency_contacts.py

Функции:

отображение экстренных контактов

загрузка данных из JSON

возврат в главное меню

3.4 Каталог объектов

Файл:

handlers/menu.py

Функции:

открытие категорий

список объектов

пагинация

открытие карточек

Каталог работает только с объектами из:

data/objects
3.5 Карточки объектов

Файлы:

handlers/card_sender.py
handlers/favorites.py
handlers/recents.py

Функции:

отправка карточки

избранное

последние просмотры

4. Слой данных

Все данные системы находятся в папке:

data/
4.1 Каталог объектов

Папка:

data/objects/

Содержит JSON-карточки:

BEAUTY_01.json
TAXI_01.json
CAFE_02.json

Каждый объект имеет поля:

id
name
category
status
description
telegram
photo
4.2 События города

Папка:

data/events/

Подразделы:

pharmacies/
electricity/
water/
emergency_contacts/

Эти данные обновляются автоматически.

5. Слой сервисов

Сервисные модули отвечают за бизнес-логику.

Примеры:

partner_request
partner_connect
bizbot
admin_tools

Этот слой может расширяться без изменения справочного ядра.

6. Реестр объектов

Файл:

bot/core/registry.py

Назначение:

загрузка всех объектов каталога

быстрый доступ по ID

Пример:

registry.get("BEAUTY_01")
7. Форматирование карточек

Файл:

bot/core/formatter.py

Функции:

форматирование карточек

HTML-разметка

подготовка текста

8. Рендер событий города

Файл:

bot/city_events/render.py

Функции:

преобразование JSON данных

подготовка текста для Telegram

9. Хранилище событий

Файл:

bot/city_events/storage.py

Функции:

загрузка данных из JSON

обработка обновлений

11. Принципы системы

AliMind построен на нескольких принципах.

Простота

Минимум экранов.

Быстрота

Пользователь получает нужную информацию за 1-2 нажатия.

Разделение слоёв

Справка, каталог и сервисы не смешиваются.

Масштабируемость

Новые модули можно добавлять без перестройки системы.
